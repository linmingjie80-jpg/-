🔄 多设备同步（GitHub）
填写后，每次点「保存」会自动推送到 GitHub，所有设备及网站访客即时看到最新内容（含照片、视频、电话号码等）。

设置步骤（约 3 分钟）：
① 登录 github.com → 点右上角头像 → 选 Settings
② 在左侧菜单拉到最底部，点 Developer settings
   → 点 Personal access tokens → 点 Tokens (classic)
③ 点右上方 Generate new token → 必须选 Generate new token (classic)（不要选 Fine-grained）
   → Note（备注）随便填，例如：花网站同步
   → Expiration（有效期）建议选 No expiration（永不过期）
   → 往下找 repo → 直接勾选 repo 整个大栏（不是里面的子项）
   → 拉到最底部点绿色 Generate token 按钮
④ 页面出现 ghp_ 开头的代码，立刻复制（只显示一次！如果是 github_pat_ 开头说明选错了，要重新选 classic）
⑤ 粘贴到下方输入框 → 点「保存所有修改」即完成
⚠ Token 只存在当前设备浏览器，不会出现在网站代码里
每台需要管理的设备单独填写一次。访客浏览网站不需要 Token。

🧾 开单系统设置（Supabase）
